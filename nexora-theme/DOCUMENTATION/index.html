NEXORA MALL — Luxury Marketplace Theme

Version: 1.0.0 | Author: Nexora Design Studios | Compatible with WordPress 6.0+ & WooCommerce 8.0+

1. Quick Theme Installation

  1. Log in to your WordPress Dashboard (/wp-admin).
  2. Navigate to Appearance > Themes.
  3. Click Add New Theme > Upload Theme.
  4. Choose the nexora-mall-theme.zip file and click Install Now.
  5. Click Activate.

2. Recommended Plugins

Nexora Mall includes built-in recommendations for the following free plugins via TGMPA:

  • WooCommerce: Complete eCommerce shop & payment engine.
  • Elementor: Drag-and-drop page builder for custom page layouts.
  • One Click Demo Import: Imports starter catalog and demo pages with 1 click.
  • Contact Form 7: Manages concierge and client inquiry forms.

3. Customizer Settings & Dark Mode

Open Appearance > Customize to adjust:

  • Gold Accent Color: Default is #d4a843.
  • Charcoal Brand Color: Default is #333333.
  • Top Bar Text: Announcement banner at the top of every page.
