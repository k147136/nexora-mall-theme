# NEXORA MALL - Luxury WordPress Theme & WooCommerce Suite

NEXORA MALL is an ultra-modern, high-performance Luxury Multi-Category E-Commerce WordPress Theme built for premium flagship brands.

## Features:
- **Full WooCommerce Integration:** Cart, Checkout, Wishlist, Quick View, and Live Product Filters.
- **Custom Elementor Suite:** 6 custom widgets (Hero Slider, Products Grid, Categories Showcase, Flash Deals, Editorial Blog, Testimonials).
- **Responsive 1-Row Gazette Blog Container:** Clean 3-article showcase.
- **Ready Installable ZIP:** `nexora-mall-theme.zip` (Ready for 1-click WP Admin upload).
